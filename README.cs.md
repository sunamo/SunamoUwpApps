# SunamoUwpApps

## Short description

NuGet balíček s pomocnými třídami, popupy, ovládacími prvky a prohlížečem ze staré UWP knihovny apps, převedený na WinUI 3 (.NET 8, Windows App SDK). Obsahuje také SunamoWriteableBitmap a SecureIt/StringSecurityHelper. Součást sbírky wnp.
